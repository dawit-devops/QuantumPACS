System Architecture

From edge to archive — a unified pipeline

📡

DICOM Ingestion

SCP listener on port 11112 accepts C-STORE from modality. Study integrity verified before commit.

🗄️

PostgreSQL Archive

10-table schema covering patient, study, series, instance, replica, and user management with asyncpg.

🖥️

Cornerstone3D Viewer

Zero-footprint web viewer with window/level, zoom, pan, and multi-series navigation.

🔐

JWT Auth

14-day token expiry, bcrypt password hashing, all endpoints authenticated by default.

🔁

Replica Sync

LISTEN/NOTIFY trigger-based replication for geo-distributed deployments.

🐳

Containerized

Single Docker image with Caddy reverse proxy + Gunicorn/Uvicorn. Non-root, health-checked.

Email Signature Kit

QuantumPACS · Copy-paste signatures for Outlook & Gmail

Every block below is a plain, email-safe HTML table with inline styles — no flexbox, no CSS classes — so it survives Outlook's Word engine and Gmail's sanitizer. Click Copy HTML, then paste into your mail client's signature editor (Gmail: Settings → Signature; Outlook: File → Options → Mail → Signatures, toggle "Edit with HTML"). Uses the PNG exports from logos/png/.

If you leave this empty, the copied HTML references png/<family>/… relative to this file. For real mail, upload the PNGs to a host and paste the absolute folder URL above — every signature updates instantly and copies with absolute image paths.

Installation & usage notes

    
    
      
  • Gmail Settings → "Signature" → paste the copied HTML into the editor. Gmail keeps inline styles; block-based layout is safe.
    • 
      
  • Outlook File → Options → Mail → Signatures → New → Edit with HTML → paste. Outlook's Word engine requires the table layout used here — do not add flexbox or CSS classes.
    • 
      
  • Images Relative PNG paths render on this page only. For outgoing mail, set the base URL above and re-copy, or upload the png/ folder and swap paths. Outlook and Gmail block remote images by default — recipients may need to click "show images"; the alt="QuantumPACS" text keeps the signature identifiable either way.
    • 
      
  • Colors Text is inline-styled (slate-800 on light, slate-100 on dark); the brand cyan accents the name. Font stack is Arial/Helvetica — universal in mail clients.
    • 
      
  • Dark mode Gmail/Outlook do not reliably support prefers-color-scheme; the dark blocks are provided for dark-themed compose windows where the light block would glare.
    • 
    

  


  

    
Send yourself a test · 5-minute pre-flight

    
    
      
  • ✓Light block — email yourself, open in Gmail (web + iOS/Android) and Outlook (desktop + web). The logo and all four text lines must render in one row, no wrap or overflow.
    • 
      
  • ✓Dark block — repeat with the dark variant on a dark-themed compose window. Slate-900 background with no pale halo around the image, and the cyan name/link still readable.
    • 
      
  • ✓Images — with "show images" enabled (Gmail) or images unblocked (Outlook), the mark loads from its hosted URL; the alt="QuantumPACS" text shows until then. Broken image? Wrong base URL or the PNG folder isn't reachable.
    • 
      
  • ✓Links — the website link and mailto/phone text work; cyan link has no unwanted underline in Outlook's Word engine.
    • 
      
  • ✓Reply-embed quirk (Outlook) — reply to your own test. Outlook pastes the entire message on reply; if the signature appears twice or loses its image, re-save the signature and re-test. Gmail: fine.
    • 
      
  • ✓Forward test — forward the test to a colleague; confirm the table doesn't collapse into stacked lines (a sign the signature editor stripped the table — re-paste as HTML).
